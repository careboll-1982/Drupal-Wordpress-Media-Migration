Bidirectional CSV-based media migration between Drupal and WordPress.

== Description ==

Exports WordPress Media Library attachments for Drupal and imports Drupal media
into WordPress. Includes browser and WP-CLI workflows, checksums, duplicate
detection, restartable batches, detailed errors, and a scoped TLS override.

== Installation ==

1. Upload and activate the plugin.
2. Open Media > Drupal WordPress Migration.
3. Choose Import from Drupal or Export for Drupal.
