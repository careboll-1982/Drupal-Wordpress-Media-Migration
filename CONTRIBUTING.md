# Contributing

Issues and pull requests are welcome. Please include the CMS versions, PHP
version, a redacted manifest row, and the exact error when reporting a problem.

Before opening a pull request:

1. Run `php -l` on every changed PHP file.
2. Validate all Drupal YAML files.
3. Test a dry run and a real import in both directions when applicable.
4. Never commit manifests containing private URLs or customer data.
