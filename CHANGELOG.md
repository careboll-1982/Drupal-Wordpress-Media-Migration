# Changelog

## 1.0.0 - 2026-08-31

- Bidirectional Drupal/WordPress CSV manifest.
- Drupal browser and Drush import/export workflows.
- WordPress browser and WP-CLI import/export workflows.
- SHA-256 integrity checks and duplicate detection.
- Restartable batches, pause/resume, fail-fast behavior, and row diagnostics.
- Configurable Drupal destination mappings.
- Optional source-scoped invalid-certificate override.
